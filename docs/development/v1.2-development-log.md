## 阶段 7：完整验证、审查、提交与推送

### 审查修复记录

独立审查发现并修复了以下问题：

- 扫描服务会尝试同一协议的全部候选 completion 端点，而不是只扫描第一个候选。
- `/v1/models` 与 `/models` 作为同一组候选处理，避免重复计分。
- HTTP 2xx 但传输断流、SSE 不完整或缺少完成事件时，不再误报协议可用。
- `ScanService::checkReady` 同步槽中重新启动扫描时，旧扫描会立即停止推进。
- BenchmarkJob 不再按相邻文本内容去重；只有带 SSE `id` 的重复事件才会去重，合法的相同文本块会保留。
- 流式响应缺少合法完成事件时，即使输出是 `OK` 也会判定为截断错误。
- 每次 fallback attempt 独立重置首字节与 attempt 时钟，TTFT 和生成耗时只统计最终成功尝试。
- Markdown 导出表头、分隔行和数据行统一列数。
- 敏感信息扫描覆盖 tracked 与 untracked 的非忽略文本文件，并对测试合成密钥使用精确 allowlist。
- 扫描与对比对话框改用统一自绘标题栏，与主窗口保持一致。
- 修复 Mock HTTP 服务器在超时连接析构时的回调生命周期问题，并连续运行 20 次超时用例验证不再崩溃。

## 阶段 8：内置 HTTP 抓包核心

### 变更

- 新增分片 HTTP 请求/响应解析器，支持 Content-Length、chunked、响应连接关闭以及输入超限。
- 新增本地 HTTP 代理，转发绝对 URL、重写上游请求行、过滤 hop-by-hop Header。
- 捕获请求/响应头、体、SSE 事件、响应状态、字节和总耗时。
- 加入 OpenAI、Claude、Claude Code、Codex CLI、Cherry Studio、ChatBox 指纹识别。
- 默认脱敏凭据，CONNECT/HTTPS 明确返回 501，不注入进程。
