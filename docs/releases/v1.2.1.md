# AI Relay Bench v1.2.1

## 发布说明

- **Windows only / 仅支持 Windows**：当前版本仅提供 Windows 64 位桌面程序。
- 修复抓包分析窗口的使用说明，明确标注 `HTTP_PROXY` / `HTTPS_PROXY` 配置方式。
- 补齐抓包功能的简体中文本地化，支持跟随系统语言自动显示。
- 新增语言包回归测试，避免资源缺失导致英文 fallback。
- 发布包不包含任何 API 地址、API Key、代理密码或用户测试数据。

## 抓包使用提示

1. 在主界面打开“抓包分析”。
2. 点击“启动抓包”，默认监听 `127.0.0.1:8765`。
3. 在 CLI 工具所在的 PowerShell 会话中设置：

```powershell
$env:HTTP_PROXY = "http://127.0.0.1:8765"
$env:HTTPS_PROXY = "http://127.0.0.1:8765"
```

4. 在同一 PowerShell 会话运行 CLI 请求，回到抓包窗口查看请求头、请求体、响应和 SSE 事件。

当前版本仅支持 HTTP 明文代理，不支持 HTTPS CONNECT / HTTPS MITM。因此大多数 HTTPS CLI 请求无法在本版本中解密查看；请求头中的 API Key 会自动脱敏。

## 安全说明

请仅在你有权调试的环境中使用抓包功能，并使用合成凭据进行回归测试。

## 安装

下载 `AI-Relay-Bench-1.2.1-win64.zip`，解压后运行 `ai-relay-bench.exe` 即可。本版本仅支持 64 位 Windows。
