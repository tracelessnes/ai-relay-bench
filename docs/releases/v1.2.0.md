# AI Relay Bench v1.2.0

## 发布说明

- **Windows only / 仅支持 Windows**
- 提供 Qt 6 MinGW Release 便携版
- 支持 OpenAI、Claude、Codex/Responses 三种协议
- 支持模型扫描、单次测试、批量测试与多轮稳定性测试
- 支持 TTFT、生成速度、总延迟、Token 用量、P50/P95 等指标
- 内置 HTTP 抓包代理，可查看 CLI 工具请求头、请求体和 SSE 数据
- 当前版本不包含 HTTPS CONNECT MITM 解密功能
- 支持中英文界面、深色/浅色主题和自定义语言包

## 安全说明

发布包不包含任何 API 地址、API Key、代理密码或用户测试数据。请在本地运行程序后自行配置测试 Profile。API Key 在 Windows 上使用系统 DPAPI 保护。

## 安装

下载 `AI-Relay-Bench-1.2.0-win64.zip`，解压后运行 `ai-relay-bench.exe` 即可。此版本仅支持 64 位 Windows。
