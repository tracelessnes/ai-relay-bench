# V1.2 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 AI Relay Bench 上实现可追踪的 V1.2：安全脱敏、链路计时、协议扫描、多站点对比、故障注入测试和 CI。

**Architecture:** 先把脱敏、链路指标、URL 候选生成、扫描能力和对比统计设计成可独立测试的领域/服务模块，再接入现有 BenchmarkJob、BenchmarkController、ExportService 和 Qt Widgets UI。网络层继续使用异步 QNetworkReply，不在 UI 线程执行阻塞请求。

**Tech Stack:** C++20、Qt 6.7+ Core/Gui/Widgets/Network/Sql/Test、CMake 3.24+、GitHub Actions Windows。

**Spec:** `docs/superpowers/specs/2026-08-22-v1.2-design.md`

## Global Constraints

- 不记录或导出真实 API Key、代理密码和 GitHub 凭据。
- 所有网络请求继续异步执行，UI 不得阻塞。
- 新字段兼容旧 SQLite/JSON 记录，缺失时使用 `-1` 或空值。
- 新增行为先写失败测试，再写最小实现，再运行全量测试。
- Base URL 必须支持有 `/v1` 和无 `/v1` 两种写法，禁止重复 `/v1`。
- 原始响应默认脱敏；完整原文只能由用户在本地明确查看，导出强制脱敏。
